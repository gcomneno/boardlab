# Sources policy

[English](README.md) | [Italiano](README.it.md)

This directory records bibliographic references, source pointers, and
publication-safe source notes used during BoardLab study sessions.

It is not a storage location for source material itself.

## Allowed public content

Public files may contain:

- bibliographic references;
- links to official publisher or designer pages;
- references to specific rulebook sections or concepts;
- short source notes that do not reproduce substantial protected text;
- distinctions between source material and original BoardLab interpretation.

## Material that must remain private

Do not commit:

- commercial rulebook PDFs;
- scanned manuals or rule sheets;
- photographs or scans of protected components;
- card artwork or board artwork;
- substantial collections of card text;
- integral or substantial copied rules;
- transcripts of protected source material;
- purchased books, ebooks, magazines, or private study corpora.

When private source material is needed locally, store it under:

`sources/private/`

That path is ignored by Git and must never enter the public repository history.

## Original BoardLab material

BoardLab should prefer publication-safe learning artifacts such as:

- original explanations;
- original diagrams;
- original examples;
- original exercises and quiz questions;
- original game designs such as Tre Sigilli;
- original analyses and comparisons.

Source references must guide study without turning this repository into a
replacement for the original game, rulebook, book, or editorial product.
