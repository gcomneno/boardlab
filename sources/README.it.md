# Politica delle fonti

[English](README.md) | [Italiano](README.it.md)

Questa directory registra riferimenti bibliografici, riferimenti puntuali alle
fonti e note sulle fonti pubblicabili utilizzate durante le sessioni di studio
di BoardLab.

Non è una posizione in cui conservare il materiale sorgente stesso.

## Contenuti pubblici consentiti

I file pubblici possono contenere:

- riferimenti bibliografici;
- link a pagine ufficiali di editori o game designer;
- riferimenti a specifiche sezioni di regolamenti o concetti;
- brevi note sulle fonti che non riproducano quantità sostanziali di testo
  protetto;
- distinzioni tra materiale sorgente e interpretazione originale BoardLab.

## Materiale che deve restare privato

Non committare:

- PDF di regolamenti commerciali;
- manuali o fogli di regole scansionati;
- fotografie o scansioni di componenti protetti;
- artwork di carte o tabelloni;
- raccolte sostanziali di testi delle carte;
- regolamenti copiati integralmente o in parte sostanziale;
- trascrizioni di materiale sorgente protetto;
- libri, ebook, riviste acquistati o corpus di studio privati.

Quando è necessario conservare localmente materiale sorgente privato, usare:

`sources/private/`

Questo percorso è ignorato da Git e non deve mai entrare nella cronologia
pubblica del repository.

## Materiale originale BoardLab

BoardLab dovrebbe preferire artefatti didattici pubblicabili come:

- spiegazioni originali;
- diagrammi originali;
- esempi originali;
- esercizi e domande di quiz originali;
- giochi originali come Tre Sigilli;
- analisi e comparazioni originali.

I riferimenti alle fonti devono guidare lo studio senza trasformare questo
repository in un sostituto del gioco, del regolamento, del libro o del prodotto
editoriale originale.
