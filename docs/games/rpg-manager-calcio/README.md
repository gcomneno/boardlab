# RPG Manager Calcio

Sottoprogetto di **GiadaWare BoardLab**: gestionale calcistico RPG con rose procedurali, progressione individuale, simulazione a possessi e decisioni situazionali dell'allenatore.

**Stato:** Design Freeze 1.0 approvato; contratto M001 v1.0 documentato; implementazione non avviata.
