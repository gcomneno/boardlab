# Study sessions

[English](README.md) | [Italiano](README.it.md)

## Purpose

This directory contains BoardLab's canonical structured learning paths.

Repository preparation and active study are tracked separately.

A session may be fully prepared before the learner starts studying it.

## Sessions

### Session 01 — Modeling a board game as a state-transition system

[Open Session 01](session-01-modeling-a-board-game/README.md)

Planned scope:

- game state;
- legal moves;
- state transitions;
- terminal states;
- players;
- strategies;
- match coordination;
- separation between game rules and decision algorithms.

Repository preparation: **Prepared**.

Active study: **not studied**.

## Status meanings

**Preparation in progress** means the public learning artifacts are still being
designed, assembled, or validated.

**Prepared** means the learning path, assessments, navigation, publication
checks, and repository-wide validation are complete.

**Studied** requires the learner to actually attempt exercises and assessments
and review the resulting gaps.

Prepared does not mean Studied.
